# AI-Driven Risk-Aware Stochastic Optimization for Renewable Microgrids

## Repository overview

This repository contains the implementation used in the paper

"AI-Driven Risk-Aware Stochastic Optimization for Renewable Microgrids."

The repository includes

• Data preprocessing

• CNN-LSTM

• Chronos-2

• PatchTST

• Persistence benchmarks

• Statistical significance testing

• Scenario generation

• Gurobi stochastic optimization

• Figures

• Supplementary material
