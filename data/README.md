# Data

## Availability

The **raw** wind and operational datasets (`data/raw/`) were collected
from an agro-export manufacturing microgrid and are subject to a
commercial confidentiality agreement with the industrial partner.
They are **not distributed** in this repository. Notebooks 01–05
(preprocessing and forecasting) therefore cannot be re-run without
access to these files; all downstream stages can.

Expected raw files (hourly resolution):

| File | Content |
|---|---|
| `raw/agregatenew.csv` | 8,375 hourly observations, 22 variables (wind speed, weather, disaggregated consumption), Jan 1 – Dec 16, 2025 |
| `raw/Renewable_energy_dataset.csv` | 3,546 hourly operational records (grid load demand, power exchange, battery state) |

## What IS included (derived, non-confidential artifacts)

### `processed/`
| File | Content |
|---|---|
| `wind_power_scenarios_kw.npy` | 1,000 × 24 dependence-preserving wind-power scenarios (kW) for the day-ahead decision problem |
| `calibrated_wind_speed_scenarios.npy` | Conformally aligned wind-speed scenarios (m/s) |
| `wind_power_scenario_statistics.csv` | Per-horizon forecast/actual/scenario statistics for the decision day |

### `optimization_input/`
| File | Content |
|---|---|
| `pgu_parameters.csv` | Four programmable generation units (output ranges, costs, ramps) |
| `battery_parameters.csv` | Battery energy-storage system (392.6 kWh) |
| `grid_parameters.csv` | Grid interconnection limits (308.9 kW import / 153.9 kW export) |
| `electricity_prices.csv` | Hourly time-of-use buy/sell prices |
| `demand_profile.csv` | Deterministic 24-h demand profile (median-demand day) |
| `representative_demand_profiles.csv` | Low/median/high/high-variability demand days |
| `reduced_wind_power_{20,50,100}_scenarios.csv` | K-means reduced scenario sets |
| `reduced_probabilities_{20,50,100}.npy` | Corresponding scenario probabilities |

These files are sufficient to reproduce the entire optimization study
(notebook 08 and the `optimization/` package): the SAA solution,
scenario-count stability, VSS/EVPI, the RP-vs-EEV comparison, the VSS
decomposition, and the out-of-sample evaluation.

### `forecasts/`
Prediction arrays saved by notebooks 02–05 for the statistical
significance analysis (notebook 06). Regenerated by running those
notebooks; not versioned by default.
