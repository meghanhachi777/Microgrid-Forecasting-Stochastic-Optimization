# Figures

Main figures of the manuscript (`newmanuscript.tex`), in order of
appearance. Vector PDFs are used in the paper where available; PNG
twins are included for quick viewing and the repository README.

| File | Manuscript figure |
|---|---|
| `schematic5.png` | Methodology schematic (pipeline overview) |
| `wind.png` | Hourly wind-speed time series (model input) |
| `chronosForecast.png` | Chronos-2 zero-shot 24-h forecast with native P10–P90 band |
| `dm_horizon_significance.png` | Horizon-wise Diebold–Mariano significance of pairwise model differences |
| `windSpeedScenarios1.png` | Dependence-preserving wind-speed scenario fan |
| `powerCurveV90.png` | Vestas V90-3.0 MW parameterized power curve |
| `windPowerScenarios1.png` | Wind-power scenarios after power-curve conversion |
| `reducedScenarios100_1.png` | K = 100 representative scenarios (K-means reduction) |
| `energyBalanceLowWind.{pdf,png}` | Hourly energy balance, low-wind scenario (~P5) |
| `energyBalanceMedianWind.{pdf,png}` | Hourly energy balance, median-wind scenario |
| `energyBalanceHighWind.{pdf,png}` | Hourly energy balance, high-wind scenario (~P95) |
| `rpVsEevRecourseCost.{pdf,png}` | Scenario-level recourse cost: stochastic (RP) vs expected-value (EEV) commitment |
| `eevCostPenalty.{pdf,png}` | Per-scenario economic penalty of the expected-value commitment |
| `vssWaterfall.{pdf,png}` | Waterfall decomposition of the value of the stochastic solution |
