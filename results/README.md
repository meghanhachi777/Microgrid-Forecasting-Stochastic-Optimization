# Results

Aggregate result tables reported in the manuscript.

| File | Content |
|---|---|
| `main_results_table.csv` | Headline stochastic-optimization results (RP, EEV, WS, VSS, EVPI, out-of-sample, runtime) |
| `vss_evpi_summary.csv`, `vss_evpi_compact.csv` | Stochastic-value analysis detail |
| `vss_decomposition.csv` | VSS decomposed by cost source (waterfall figure) |
| `rp_vs_eev_summary_table.csv` | Stochastic vs expected-value commitment summary |
| `rp_vs_eev_scenario_comparison.csv` | Per-scenario RP vs EEV comparison (100 scenarios) |
| `representative_scenarios.csv` | Low/median/high-wind representative scenarios |
| `scenario_count_comparison.csv` | SAA objective and solver stats for K = 20/50/100 |
| `scenario_reduction_metrics.csv` | Reduction-fidelity diagnostics vs the 1,000-scenario set |
| `out_of_sample_summary.csv` | 1,000-scenario out-of-sample evaluation of the RP commitment |
| `ablation_results.csv` | Deterministic-plan ablation (persistence / Chronos P50 / EV) |
| `dm_overall_results.csv`, `dm_horizon_results.csv` | Diebold–Mariano significance tests |
| `dm_main_manuscript_table.csv` | Significance table as reported in the manuscript |
